Privacy Policy

Last updated: November 2026

This Privacy Policy applies solely to this private, self-hosted n8n automation project. The application is strictly personal and non-commercial.

1. Data Accessed

The application requests access to Google APIs exclusively to execute user-configured automation routines. For Google Calendar integrations, this includes:

  • Reading calendar event details (titles, dates, times, descriptions) to trigger automation workflows.
  • Creating or modifying calendar entries as explicitly defined by the owner's workflow scripts.

2. Purpose of Data Use

Data retrieved from Google APIs is processed only to perform specific personal automations (such as sync schedules or calendar alerts). The data is never used for profiling, analytics, or secondary purposes.

3. Data Storage & Security

OAuth tokens, refresh credentials, and temporary data payloads are stored locally and encrypted within the private self-hosted n8n environment. No authentication tokens or user data are transmitted to public servers or external databases.

4. Third-Party Sharing

This application does not sell, trade, rent, or transfer any Google user data to third parties, external developers, or advertising platforms.

5. Revocation & Data Deletion

You can revoke the application's access at any point via your Google Account Security Settings. Revoking access immediately invalidates active refresh tokens.

6. Contact

If you have questions regarding this private integration, contact the system operator via the developer email address registered in the Google Cloud Console.
