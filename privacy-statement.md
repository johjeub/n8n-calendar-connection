# Privacy Policy for Personal Automation

Last updated: 9 November 2026

This application is a private, self-hosted automation tool operated solely by the developer for personal use.

1. Information Collected:
The application accesses Google Calendar data (such as event names, start/end times, and descriptions) exclusively through user-granted OAuth 2.0 permissions.

2. Use of Information:
Calendar data is processed strictly to execute user-defined automation workflows (e.g., syncing events, formatting schedules).

3. Data Sharing and Transfer:
We do not sell, rent, transfer, or share Google user data with any third parties or advertising platforms. All data remains within the private, self-hosted n8n infrastructure.

4. Data Retention and Security:
Access tokens and calendar data are stored securely on the user's private server. Access can be revoked at any time via Google Account Security settings.
